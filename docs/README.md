# Project Documentation

This folder contains the project documentation and Architecture Decision Records (ADRs) for `LRC_Player`.

## Contents

- `ADR/` — Architecture Decision Records documenting important design choices.
- `README.md` — This overview document.

## Existing Documentation

- `Architecture.md` — high-level architecture diagram and module layout.
- `Requirements_Definition.md` — product requirements and scope.
- `Specification.md` — functional specification.
- `Workflow.md` — development process and task flow.

## ADR Guidelines

Each ADR should be a short, self-contained markdown file with:

- Status
- Context and problem statement
- Decision taken
- Consequences

The ADR filenames are ordered numerically so the history of decisions is easy to follow.
