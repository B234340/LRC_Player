# LRC Player ユーザーガイド

LRC Player の使い方をまとめたガイドです。画面の名前は日本語表示のものです
（設定 → 外観 → 言語で English にも切り替えられます）。

## はじめに

1. `LRCPlayer.exe` を起動します（ポータブル版はインストール不要です）。
2. 左のメニュー「フォルダー」→「音楽フォルダー」でフォルダーを追加します。
   追加したフォルダーとそのサブフォルダーの曲がライブラリに入ります。
3. スキャンが終わると「ライブラリ」「アルバム」「アーティスト」に曲が並びます。
   曲をダブルクリックすると再生が始まります。

対応している形式：MP3、FLAC、WAV、AAC、M4A、OGG。

## 画面の構成

| 場所 | 内容 |
|---|---|
| 左のサイドバー | 再生中・再生キュー・ライブラリ・アルバム・アーティスト・プレイリスト・フォルダー・設定 |
| 下の再生バー | 曲名、再生操作、シークバー、シャッフル・リピート、歌詞パネル、再生キュー、イコライザー、信号経路、音量 |
| 右のパネル | 歌詞または再生キュー（再生バーのボタンで切り替え） |

ウィンドウの幅が狭いときは、再生バーの一部のボタンがメニューにまとまります。

## ライブラリと再生

- **再生**：曲のダブルクリック、または Enter。表示中の一覧が再生キューになります。
- **次に再生 / キューの最後に追加**：曲の行にマウスを載せたときの「⋯」から。
  曲を再生キューへドラッグすることもできます。
- **リンク**：一覧の曲名をクリックすると再生、アーティスト名・アルバム名をクリックするとそのページへ移動します。
  「← 戻る」（Alt + ←、マウスの戻るボタン）で元の一覧に戻れます。
- **並べ替え**：列の見出しをクリック。見出しを右クリックすると、年・ジャンルの列を表示できます。
- **お気に入り**：再生バーや曲の行のハートで登録します。サイドバーの「お気に入り」に集まります。
- **プレイリスト**：サイドバーのプレイリストから作成。再生キューをプレイリストとして保存することもできます。
- **ギャップレス再生**：アルバムの曲間が途切れずにつながります。

## 歌詞

### 歌詞ファイルの置き方

歌詞は `.lrc` ファイルから読み込みます。次のどちらかに置いてください。

1. **曲と同じフォルダーに同じ名前で置く**（おすすめ）

   ```text
   01 夜の駅.flac
   01 夜の駅.lrc
   ```

2. **歌詞だけを別のフォルダーにまとめる**：「フォルダー」→「歌詞フォルダー」に追加すると、
   その中の `.lrc` を曲名・アーティスト名で照合して読み込みます。

### LRC の書式

行単位のタイミングは `[分:秒.百分の一秒]` で書きます。

```text
[00:12.00]最初の行
[00:17.50]次の行
```

文字単位（カラオケ）のタイミングは、行の中に `<分:秒.百分の一秒>` を入れます。
文字単位のタイミングがある行は、歌っている位置まで左から塗りつぶされます。

```text
[00:12.00]<00:12.00>最初<00:12.80>の<00:13.10>行<00:13.60>
```

### 歌詞の表示を調整する

- **カラオケ表示**（設定 → 歌詞）：文字単位のタイミングがある行を塗りつぶします。
- **文字タイミングを推定**（設定 → 歌詞）：行単位の歌詞も、読みの長さ（かな・漢字の拍数）から
  タイミングを推定して塗りつぶします。表示だけで、ファイルは変更しません。
- **タイミングのずれ**：再生画面の −/＋ で曲ごとのオフセットを調整できます（曲ごとに記憶されます）。
- **歌詞全体を行・文字単位でずらす**：歌詞パネルの「⋮」から。歌詞の文字が 1 行・1 文字ずれている
  ファイルを直すときに使います。保存すると元のファイルは `.bak` として残ります。
- **クリックでシーク**：歌詞の行をクリックすると、その位置へ移動します。

### 歌詞をインターネットから取得する（LRCLIB）

- **自動取得**（設定 → 歌詞 →「歌詞を自動取得」）：歌詞が見つからない曲を再生したときに
  [LRCLIB](https://lrclib.net) で検索し、見つかった LRC を曲と同じフォルダーに保存します。初期状態はオフです。
- **まとめて取得**（設定 → 歌詞 →「歌詞のない曲をまとめて取得」）：ライブラリ全体の歌詞のない曲を
  1 曲ずつ検索します。実行前に送信内容の確認が出ます。見つからなかった曲は 30 日間再検索しません。
- 送信するのは曲名・アーティスト名・アルバム名・再生時間だけです。既存のファイルは上書きしません。

### 音声から文字タイミングを作る（lrc-align）

行単位の LRC に、曲の音声から文字ごとのタイミングを付ける補助ツールです（Python が必要）。
インストール方法は [lrc-align の README](../tools/lrc_align/README.md) を参照してください。
インストール後、歌詞パネルの「⋮」→「音声から文字タイミングを生成」で使えます。

## デスクトップ歌詞

ほかのアプリの上に浮かぶ小さな歌詞ウィンドウです。メイン画面を最小化しても表示され続けます。

- **表示 / 非表示**：再生バーのボタン、歌詞パネルの「⋮」、設定 → 歌詞 → デスクトップ歌詞、
  または Ctrl + Shift + L。
- **移動・大きさ**：ドラッグで移動、端をドラッグで大きさを変更。位置は次回も保たれます。
  見失ったときは設定の「位置をリセット」で戻せます。
- **マウスを載せると出るボタン**：前の曲・再生/一時停止・次の曲、文字サイズ、背景の透明度、
  ロック、メイン画面を開く、閉じる。
- **アルバムアート**：設定の「アルバムアートを表示」でオン / オフ。
- **ロック（クリック透過）**：ロック中は歌詞ウィンドウの下にあるアプリをそのままクリックできます。
  マウスが歌詞の上にある間は歌詞が薄くなり、描画を止めて軽くします。
  解除は再生バーのボタン、設定、または Ctrl + Alt + L で行います（歌詞ウィンドウ自身では解除できません）。

## 音質の設定

設定 →「音質」にまとまっています。

| 項目 | 内容 |
|---|---|
| 音量の正規化 | 曲ごと / アルバムごとに音量をそろえます。ReplayGain タグがあればそれを使い、なければ再生時に EBU R128 で測定します。「ライブラリを解析」で事前に全曲を測定できます。初めて再生する未測定の曲は、その 1 回だけ正規化されません |
| プリアンプ / 音割れを防ぐ | 正規化後の音量の補正と、ピークが 0 dBFS を超えないようにする設定 |
| クロスフィード | ヘッドホンで左右の音を少し混ぜ、スピーカーに近い定位にします（弱 / 中 / 強） |
| 自動ヘッドルーム | イコライザーで持ち上げた分だけ音量を下げ、音割れを防ぎます |
| ディザー | 16/24 ビット整数で出力するとき、音を加工している場合だけ使います |
| 排他モード（WASAPI） | Windows のミキサーを通さずに出力します。曲のサンプルレートのまま出力するので、リサンプリングが入りません。使えないときは自動で通常の出力に戻ります |
| 信号経路 | 再生中の曲がどの処理を通っているかを表示します。再生バーの波形ボタンからも見られます |

信号経路の表示：

- **ビットパーフェクト**：排他モードで、アプリ内でも何も加工していない状態
- **アプリ内は無加工**：アプリでは加工していないが、OS のミキサーを通っている状態
- **加工あり**：音量・イコライザー・正規化などで音を変えている状態

## イコライザー

再生バーのイコライザーボタンで開きます。「グラフィック」と「パラメトリック」のタブがあり、
両方を同時に使えます。グラフに合成した周波数特性が表示されます。

### グラフィック EQ

10 バンドのイコライザーとプリセット、プリアンプ。

### パラメトリック EQ

- 最大 20 個のフィルター（ピーク、ローシェルフ、ハイシェルフ、ローパス、ハイパス）。
  周波数・ゲイン・Q を数値で編集できます（「1.2k」のような入力も可）。
- **AutoEq ファイルを読み込む / クリップボードから貼り付け**：Equalizer APO / AutoEq 形式の
  パラメトリック EQ 設定を読み込みます。
- **L+R（共通）/ L・R 別**：左右に同じフィルターを使うか、チャンネルごとに別のフィルターを使うかを選びます。
  L・R 別では、編集するチャンネル（L / R）を選び、「L → R にコピー」などで複製できます。

### 自動作成（ターゲットに合わせる）

イヤホン・ヘッドホンの測定データを、ターゲットの周波数特性に近づけるフィルターを自動で計算します。

1. 「自動作成（ターゲットに合わせる）」を開きます。
2. **ターゲット**：ターゲットカーブのファイルを読み込むか、「フラット」を選びます。
3. **測定データ**：測定した周波数特性のファイルを読み込みます。
   L・R 別のファイルを読み込むか、「L と R に同じ測定データを使う」を選べます。
4. 必要ならフィルター数・最大ゲイン・Q の範囲・周波数範囲・高音域で持ち上げる量の上限・
   シェルフの使用を調整し、「フィルターを作成」を押します。
5. 補正前後の誤差（RMS）が表示され、グラフにターゲット・測定・補正後の予測が重なります。
   結果は元に戻すボタンで取り消せます。

| モード | 1 つの測定データを L と R に使う | L と R を別々に読み込む |
|---|---|---|
| L+R | その測定データに合わせる | L と R の平均に合わせる |
| L・R 別 | 同じフィルターを両方に適用 | 左右それぞれに合わせる |

読み込めるファイル形式：

- REW のテキスト形式（`*` で始まるヘッダー行、周波数・dB・位相の列）
- AutoEQ / squig.link 形式の CSV（`frequency,raw` など）
- 区切りが空白・カンマ・セミコロンの数値列（セミコロン区切りで小数点がカンマの形式も可）
- 1 列目が周波数（Hz）、2 列目が dB。文字コードは UTF-8 / UTF-16 / Shift_JIS

## データの保存場所

すべて `LRCPlayer.exe` と同じフォルダーの `data` フォルダーに保存されます。

| ファイル | 内容 |
|---|---|
| `config.json` | 設定 |
| `state.json` | 再生キュー、再生位置、ウィンドウの位置と大きさなど |
| `playlists.json` | プレイリスト |
| `meta_cache.db` | ライブラリ（スキャン結果）のデータベース |
| `loudness.json` | 音量の測定結果 |
| `lyrics/` | 曲のフォルダーに書き込めなかったときの取得済み歌詞 |

書き込みできない場所（`C:\Program Files` など）に置くと保存できません。
アップデートは `LRCPlayer.exe` を上書きするだけで、`data` はそのまま使えます。

## 困ったときは

- **曲がライブラリに出てこない**：「フォルダー」で音楽フォルダーが登録されているか確認し、
  「再スキャン」を押してください。対応形式は MP3 / FLAC / WAV / AAC / M4A / OGG です。
- **歌詞が表示されない**：`.lrc` が曲と同じ名前か、歌詞フォルダーに登録した場所にあるかを確認してください。
- **歌詞が少しずれる**：再生画面の −/＋ でオフセットを調整してください。行や文字が丸ごとずれている
  場合は、歌詞パネルの「⋮」の「行ずらし / 文字ずらし」を使います。
- **音が出ない**：設定 → 再生 → 出力デバイスを確認してください。排他モードがほかのアプリと
  競合している場合は、通常の出力に自動で戻ります。
- **音が途切れる**：排他モードで途切れる場合は、オフにして試してください。
- **「lrc-align が見つかりません」と出る**：[lrc-align の README](../tools/lrc_align/README.md#lrc-align-が見つかりませんと出るとき) を参照してください。
